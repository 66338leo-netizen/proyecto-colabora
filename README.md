Instrucciones a seguir
1. Realiza un FORK del repositorio original
2. Realiza un CLONE a tu repositorio local
3. Crea una RAMA (BRANCH) para realizar tu aportación.
La aportación será escribir tu nombre en la lista de participantes
4. Realiza un PUSH a tu repositorio en github
5. Realiza un Pull Request y espera aceptación
6. Sincroniza tu FORK
